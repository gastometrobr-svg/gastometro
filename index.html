Política de Privacidade

Versão 1.0 — GastôMetro · MRQ Log · Atualizado em 07/08/2026
1. Responsável
Miqueias Ribeiro Queiroz (MRQ Log), Uberlândia/MG.

2. Dados Coletados
O app coleta apenas o que você insere voluntariamente:
✔ Nome de cadastro
✔ Valores e descrições de gastos
✔ Senha de acesso
NÃO coletamos: localização, e-mail, CPF, contatos ou dados bancários.
3. Finalidade
Os dados são usados exclusivamente para o funcionamento do app. Não são compartilhados com terceiros nem usados para publicidade.
4. Armazenamento
Dados armazenados no Firebase (Google Cloud), com certificações de segurança internacionais. Cada usuário tem código único e dados completamente isolados.
5. Seus Direitos (LGPD)
✔ Acessar seus dados diretamente no app
✔ Corrigir ou atualizar a qualquer momento
✔ Solicitar exclusão total via WhatsApp
6. Segurança das Senhas
As senhas são armazenadas exclusivamente em formato criptografado (SHA-256) e nunca são acessíveis ao administrador do sistema, nem a terceiros.
🔒 Senhas criptografadas com SHA-256 — ninguém vê sua senha real.

🔑 Em caso de recuperação de acesso, o administrador pode resetar a senha para um valor padrão temporário.

✅ O usuário é obrigado a criar uma nova senha pessoal após o acesso com a senha temporária.
7. Retenção
Dados ficam armazenados enquanto a conta estiver ativa. Contas sem acesso por mais de 12 meses podem ser removidas mediante aviso prévio.
